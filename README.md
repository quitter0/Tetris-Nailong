# Tetris-Nailong（俄罗斯奶块）

一个用 **原生 Win32 + GDI**（无任何游戏框架）从零实现的俄罗斯方块，主题素材为"奶龙"。纯 C++ 编写，单窗口、双缓冲渲染，支持难度选择、道具、炸弹方块、连击计分与最高分存档。

## 功能特性

- **经典玩法**：15×25 棋盘，7 种经典方块 + 奶龙主题贴图。
- **难度选择**：启动时弹出难度对话框，影响下落速度与炸弹方块出现概率。
- **炸弹方块**：特殊方块，落地后引爆并清除周围格子。
- **道具系统**：一键消除底层、减速下落、双倍得分。
- **连击计分**：连续消行累积 Combo 加成。
- **瞄准器**：可切换半透明落点提示，方便精确落位。
- **最高分存档**：自动保存/读取历史最高分（存于 exe 同目录 `highscore.dat`）。
- **自适应窗口**：按设计分辨率等比缩放并居中，小屏也能完整显示；窗口缩放不变形。
- **音效**：背景音乐（循环）与游戏结束音效。
- **无闪烁渲染**：全程离屏双缓冲，拦截系统背景擦除。

## 操作说明

| 按键 | 功能 |
|---|---|
| `←` / `→` | 左右移动方块 |
| `↑` | 旋转方块 |
| `↓` | 加速下落 |
| `空格` | 直接落到底部 |
| `P` | 暂停 / 继续 |
| `T` | 切换瞄准器（落点提示） |
| `1` | 道具：消除底层一行 |
| `2` | 道具：减速下落 |
| `3` | 道具：双倍得分 |
| `R` | 重新开始 |

## 难度

| 难度 | 下落间隔 | 炸弹方块概率 |
|---|---|---|
| 简单 | 800 ms | 15% |
| 普通 | 500 ms | 10% |
| 困难 | 300 ms | 4% |

> 难度越高，下落越快、炸弹越少。简单模式的非炸弹方块只在 0~6 号类型中随机，普通/困难模式则在 0~13 号类型中随机。

## 编译与运行

**环境要求**

- Visual Studio 2022（需安装「使用 C++ 的桌面开发」工作负载）
- 平台工具集 v145，目标平台 Win32 (x86)
- 语言标准 C++17

**步骤**

1. 用 Visual Studio 打开 `Tetris/Tetris.sln`。
2. 选择配置 `Debug | Win32`。
3. 按 `F5` 运行（或 `Ctrl+Shift+B` 生成）。

> 生成产物输出到 `Tetris/Tetris/Win32/Debug/Tetris.exe`。
> 也可以直接用 `MSBuild.exe Tetris.sln -p:Configuration=Debug -p:Platform=Win32` 命令行编译。
> "最高分存档" `highscore.dat` 会在首次刷新纪录时自动生成在 exe 所在目录，无需手动创建。

**直接运行**

双击 `Tetris/Tetris/Win32/Debug/Tetris.exe`，先在对话框中选难度即可开始。

## 目录结构

```
.
├─ Tetris.sln                      解决方案
├─ Tetris/Tetris/
│  ├─ Tetris.cpp / Tetris.h        程序入口、窗口与消息处理
│  ├─ TetrisLogic.cpp              游戏逻辑（方块、消行、道具、计分、存档）
│  ├─ TetrisRender.cpp             渲染与音效
│  ├─ stdafx.h / stdafx.cpp / targetver.h
│  ├─ Tetris.rc / resource.h       资源脚本与 ID 定义
│  └─ *.bmp / *.wav / *.ico        贴图、音效、图标素材
└─ README.md
```

## 素材说明

- 贴图：`background.bmp`、`brick1~6.bmp`、`brick14.bmp`（炸弹方块）、`GAMEOVER.bmp`
- 音效：`background.wav`（背景音乐）、`laughing.wav`（结束音效）
- 图标：`Tetris.ico`、`small.ico`

所有素材均以资源形式编入 exe，运行时不依赖外部文件。
